LawMitra AI

AI-powered Indian Legal Guidance and Case-Routing Platform

Project Documentation Report

Project type: Front-end web application / legal-guidance prototype

Technology: HTML, CSS, JavaScript ES modules, and browser storage

Purpose: Help citizens understand common legal and civic problems, preserve evidence, identify escalation routes, and create first-draft complaints.

This project provides general information. It does not replace a qualified lawyer, legal-aid office, or emergency service.

1. Project Overview

LawMitra AI is a browser-based chatbot for common Indian legal and civic questions. A user describes an issue in simple language. The system identifies the closest curated case type and returns a structured answer with possible remedies, evidence to preserve, immediate steps, contact options, official sources, and complaint drafts.

Problems addressed

  • Citizens may not know which legal area applies to their problem.
  • They may not know what documents, screenshots, messages, or payment records to preserve.
  • They may need a simple starting point before approaching legal aid, a regulator, police, or a lawyer.

Main objectives

  1. Classify common legal and civic problems safely.
  2. Give readable and practical first guidance.
  3. Provide evidence checklists, escalation routes, official links, and draft formats.
  4. Keep chat history optional and browser-local.
  5. Prioritise emergency guidance over normal case matching.

3. Working Flow

  1. The user enters a message in the chat.
  2. The message is normalised: lowercase, clean spaces, and reduced repeated letters.
  3. The app checks greetings, thanks, and goodbye messages first.
  4. It scores legal-category keywords and checks confidence.
  5. High-confidence messages receive the closest case guidance.
  6. Low-confidence or ambiguous messages get a safe clarification request instead of a guess.
  7. Urgent safety messages are handled before ordinary case matching and direct the user to 112.

5. Key Features and Improvements

Safe confidence-based routing

The chatbot does not force every message into a legal category. For example, a greeting receives a friendly response. An unclear issue gets a follow-up question. This reduces unrelated or alarming answers.

State/UT context and official sources

Users can select an optional State/UT. The response then reminds them that local process can differ. Case responses include official links such as India Code, NALSA, the National Cyber Crime Reporting Portal, RBI, MCA, Passport Seva, Election Commission, IP India, and Income Tax e-Filing.

Emergency escalation

Words indicating immediate danger, violence, assault, threats, stalking, blackmail, or self-harm are prioritised for urgent guidance. The system directs the person to call 112 before ordinary legal steps.

Evidence and drafting support

Matched cases can show evidence checklists, immediate actions, potential remedies, escalation options, nearby-help maps, ready-to-send email drafts, and short-message drafts.

Mobile and privacy UI updates

  • The responsive sidebar works on phone, tablet, and desktop layouts.
  • The All Cases action now explicitly restores the catalogue and smoothly scrolls the internal chat area to it on mobile devices. It no longer relies only on ordinary in-page anchor behaviour.
  • The History & privacy control uses a blue highlighted treatment with a border, glow, and visible active state. This clearly separates it from ordinary chat suggestions.

Coverage improvement and local catalogue tool

Unclassified queries create a local coverage-gap record with confidence and keyword signals only; raw user text is not stored for this purpose. A development-only local JSON import/export tool supports vetted case entries in the current browser.

6. History, Privacy, and Safety

User choiceBehaviour
YES — Save My HistoryStores persistent YES consent and a random browser UUID in cookies. Conversation content is stored locally under that browser ID and can reload later.
NO — Not NowDoes not store a persistent NO preference or browser ID. It closes the dialog for the current page and appears again after refresh or a future visit.
Stop saving historyRemoves persistent consent and browser-ID cookies.
Delete all saved historyRemoves saved conversations associated with the active browser ID.

The State/UT setting is session-only. Coverage-gap export stores routing signals, not raw message content.

8. Running the Project

  1. Open a terminal in the project folder.
  2. Run python -m http.server 8080.
  3. Open http://localhost:8080 in a browser.
  4. Try prompts such as “My landlord is not returning my deposit” or “I lost money in a UPI scam.”

9. Limitations and Future Scope

  • The system provides general information, not final legal advice or legal representation.
  • It cannot guarantee 100% legal coverage because laws, local procedures, and court decisions change.
  • The present version has no backend, authentication, shared database, or legally reviewed publishing workflow.
  • A production system should add a secure backend, role-based access, lawyer/editor review, audit logs, versioned content, rate limits, security review, and scheduled source updates.

10. Viva Questions and Answers

What is LawMitra AI?
A browser-based legal-guidance and case-routing project for common Indian legal and civic issues.
Does it use a large language model API?
No. This version uses transparent curated data, keywords, and confidence scoring, which makes it easier to explain and test.
How does it avoid wrong classification?
It checks confidence and ambiguity. If the evidence is weak, it asks for clarification instead of guessing.
How is privacy handled?
Saved history is opt-in. YES persists locally; NO is not stored persistently. The project has no server database.
How does it handle emergencies?
Urgent safety indicators are checked before ordinary routing, and the user is directed to 112.
What is the main production limitation?
The app needs a secure backend and professional legal-content review before public deployment.

11. Conclusion

LawMitra AI demonstrates a practical, privacy-conscious way to make legal information easier to understand. It combines curated Indian legal categories, safe routing, evidence and drafting support, official-source links, emergency escalation, mobile-friendly navigation, and user-controlled history. It is suitable as an academic project and a controlled prototype, with a clear path toward a professionally reviewed production platform.
